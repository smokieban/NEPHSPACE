## ⚙️ Setup Instructions

1. **Upload Files**
   - Upload all files to your web server (XAMPP, live server, etc.)
   - Ensure PHP is enabled on your server

2. **Add Images**
   - Create `assets/img/` folder if it doesn't exist
   - Add all required images (see list above)
   - Use high-quality images for best results

3. **Configure Contact Form**
   - Open `contact.php`
   - Update line 60: Change `info@nephspace.co.ke` to your email
   - Update email addresses in the auto-reply function

4. **Customize Content**
   - Update company information in `index.html`
   - Modify contact details (phone, email, address)
   - Adjust social media links

5. **Test**
   - Open `index.html` in a browser
   - Test all navigation links
   - Submit the contact form to verify email delivery
   - Check responsiveness on different devices
